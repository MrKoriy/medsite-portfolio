# BRIEF: Медицинский сайт с админкой и онлайн-записью (портфолио-прототип)

## Контекст
Портфолио-проект: сайт медицинской организации с собственной админ-панелью
и системой онлайн-записи к врачам. Строится как витринный fullstack-кейс.

## Архитектурное ограничение (СТРОГО)
Проект делится на два изолированных компонента:
- `backend/` — FastAPI + SQLite (SQLAlchemy), JSON REST API, админка.
- `frontend/` — статический сайт: HTML/CSS/JS (без сборщиков), общается с API по HTTP.

Агенты НЕ имеют права писать вне своей директории. Контракт между ними —
API-спецификация из PLAN.md.

## Функциональные требования
1. **Публичная часть**: главная, список услуг, страница врача (специалисты),
   FAQ, контакты, форма онлайн-записи (имя, телефон, врач, услуга, дата/слот).
2. **Админ-панель** (простая авторизация по токену/паролю):
   - управление услугами (CRUD), врачами (CRUD), FAQ (CRUD);
   - просмотр заявок онлайн-записи, смена статуса (новая/подтверждена/отменена);
   - настройки SEO (title/description для страниц).
3. **Лиды/аналитика**: форма захвата пишет UTM-метки, clientID (из cookie),
   leadID (uuid), источник.
4. **Безопасность**: хеширование пароля (bcrypt/passlib), параметризованные
   запросы (ORM), валидация входных данных (pydantic), CORS под frontend.
5. **Персональные данные**: маскирование телефона в логах, пометка что БД ПД.

## Технические требования
- Python 3.12, FastAPI, SQLAlchemy 2.0, SQLite (файл `backend/medsite.db`).
- Запуск: `uvicorn app.main:app --reload` из `backend/`.
- Frontend открывается статикой (http.server или через FastAPI static mount),
  конфиг API-URL в одном месте (`frontend/config.js`).
- Тесты: pytest на backend (минимум: health, услуги CRUD, запись на приём,
  авторизация админа). Тесты обязаны проходить.
- Без тяжёлых зависимостей. requirements.txt в backend/.
- README.md в корне: как поднять и что где лежит.

## Критерии готовности
- `pip install -r backend/requirements.txt` проходит.
- Сервер стартует, `/api/health` отвечает 200.
- Через API создаются услуга/врач, через форму создаётся заявка, в админке видно.
- `pytest` зелёный.
